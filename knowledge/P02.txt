Knowledge record: P02-M01
Type: AI Models

Model type: Hybrid pump physics plus pooled random forest and per-well linear regression; weighted prediction of increments; constrained grid search

Inputs: Current state, lagged/smoothed state, historical changes, proposed frequency change, static/pump data and economic data

Outputs: Post-change critical parameters, production response and recommended frequency/duty

Reported performance: One-sided intake-pressure prediction error ≤2.4×10^4 kg/m² for 99% of source cases; no full-model accuracy statistic. Production uplift 1.5% is not accuracy.

Advantages: Increment prediction reduces slowly varying reservoir measurement bias; pooled model supports sparse individual histories; uncertainty included.

Limitations: Stable wells only; blending confidence algorithm undisclosed; network interference and equivalent injection unresolved; geologist approves settings; sample-count/pressure-unit discrepancies.

Data feasibility: Avalon alone: no. Combined three user sources: partial; need static equipment/fluid metadata, valid downhole CIPs, insulation, energy/prices and reservoir context. Injection response not solved.

Complexity: High

Prediction target: Response to control changes and constraint crossing; not validated remaining life.

Lead time qualification: Motor response 2–3 hours and intake response 5–10 days; no failure horizon.

Signals: State, history, CIPs, production, pump model and metadata.

Source thresholds: Field-specific values and unit discrepancy in Section 6.

Implementation proposal: First implement data-quality and stability gates, then shadow-test recommendations with uncertainty and human approval; use tests to verify incremental oil.

Recommended future model: Hybrid response-to-frequency model; duty-cycle optimizer; later network and producer–injector optimization.
