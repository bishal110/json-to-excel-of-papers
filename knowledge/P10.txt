Knowledge record: P10-M01
Type: AI Models

Model type: Linear-kernel SVM with domain-engineered daily features and sliding-window ratios; hyperparameters cross-validated

Inputs: Current, voltage, frequency, runtime and quality/event labels

Outputs: Normal versus anomaly/inefficiency

Reported performance: Overall precision 61.8%, recall 61.5%; FMT1 62.5%/70%; FMT2 50%/33.3%. Separate years used for train/test; hundreds of wells. TP-I event recall and TP-II alert precision use ±90-day matching and differ in counting.

Advantages: No downhole sensor needed; fleet normalization and practical electrical features.

Limitations: Labels subjective; inefficiency versus failure confused; 90-day window can inflate usefulness; no fixed RUL; copying prior data can manufacture patterns.

Data feasibility: Avalon alone conditionally sufficient for scoring if four raw tags and history exist; event/maintenance labels still needed for training. Tests/surface pressures useful for diagnosis, not original inputs.

Complexity: Medium

Prediction target: Anomalous/inefficient state associated with future reported events.

Lead time qualification: 90 days is evaluation tolerance, not demonstrated per-event warning time.

Signals: Electrical, runtime, quality and confirmed events.

Source thresholds: Site maximum current for cleaning; no universal failure thresholds; SVM boundary learned.

Implementation proposal: Strong surface-only baseline candidate; retain missingness, mask planned cycling, evaluate chronological run-held-out event precision/recall and false alerts per well-month.

Recommended future model: Surface-only linear SVM or tree benchmark using electrical/runtime features.
