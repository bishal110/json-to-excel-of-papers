Knowledge record: P13-M01
Type: AI Models

Model type: Random forests for failure events; CNN dynacard descriptors; shallow trees/RF for suboptimal states; generalized supervised workflow

Inputs: Rod controller, pressure, load, fillage, dynacard and event labels

Outputs: Fault/suboptimal-event classes and scores

Reported performance: Tubing test accuracy .995, precision .546, hourly recall .421; event detection 80/133=60.2%, 66 false interventions. Pump CV precision .714, accuracy .875, recall .996; event detection 113/172=65.7%, 45 false interventions. CNN descriptor precision/recall vary .596–.955/.651–.983. These are rod results; abstract >99% does not describe all models.

Advantages: Whole-well CV, event aggregation, explicit false interventions and quality gates.

Limitations: Rod-specific features; imbalance (~1% failure time) inflates accuracy; retrospective labels use later evidence; cannot use those future observations live; small suboptimal-event cohorts.

Data feasibility: No direct ESP reproduction from Avalon/test/pressure sources; methodology transfers after new ESP features/labels. Gas-lift extension is not water-injection evidence.

Complexity: High

Prediction target: Rod failure/suboptimal states; ESP extension proposed.

Lead time qualification: 31-day life-estimation error in abstract is not warning time; no validated ESP lead.

Signals: Rod-specific six core signals and event labels.

Source thresholds: Model scores .5/.75; eligibility 4 h/50 d, not ESP alarm limits.

Implementation proposal: Transfer data eligibility, whole-well/time holdouts and event-level alert accounting to an ESP pilot.

Recommended future model: ESP event detector using own electrical/production features and whole-event scoring.

Review status: Pending

Source caveats: No evidence for autonomous ESP control. ROC AUC is ranking discrimination, not accuracy; false-positive rate is 1−specificity, despite source wording.
