Knowledge record: P05-M01
Type: AI Models

Model type: Robust PCA (configured for 25% outliers), T² surveillance, contribution diagnostics, quadratic conditional operating bands

Inputs: 22 measured/derived variables; one-minute historian plus event records

Outputs: Health trajectory, scalar anomaly score, ranked contributions and suggested stable bands

Reported performance: >96% explained variance is not detection accuracy. All studied events reportedly detected hours early; event denominator/false-positive rate and independent prospective test not supplied.

Advantages: Interpretable visual trajectory and contributors; relatively modest mathematical complexity.

Limitations: Linear normal model; correlated data; anonymized inputs; fixed-other-variable bands are not causal control policy; no held-out performance counts.

Data feasibility: Full replication requires downhole/thermal/vibration/leakage data and unnamed tags. A reduced Avalon+surface-pressure model is feasible as a new validated model; sparse production tests add context, not minute-scale signals.

Complexity: Medium

Prediction target: Developing multivariate instability preceding some trips.

Lead time qualification: Hours; one illustrated ~30-hour interval.

Signals: Historian variables, event log and clean healthy baseline.

Source thresholds: 95% F-distribution boundary; figure example T² boundary near 10, not transferable.

Implementation proposal: Build regime-specific robust PCA with run-state masks, contributor display, persistence and false-alert evaluation; keep recommendation assessment outside raw contribution ranking.

Recommended future model: Robust PCA baseline for sensor-rich wells, separate surface-only baseline, later fault classifier.

Review status: Pending

Source caveats: Printed claims that all individual values inside bands guarantee healthy joint scores are stronger than conditional mathematics warrants. Full original feature list is unavailable.
