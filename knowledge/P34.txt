Knowledge record: P34-D01
Type: Rules

Rule name: Current-period segmentation

Source status: do_not_deploy_as_written

IF: Motor current remains>0

AND: No intervening zero-current stop

THEN: Treat as one uninterrupted motor-current period.

Engineering explanation: Restart begins a new period; a stop is not automatically failure.

Alternative causes: Other source-specific conditions plus operating changes and data errors; no quantified comparative likelihood.

Recommended checks: Verify premises, units, operating state and data freshness. Restart begins a new period; a stop is not automatically failure.

Knowledge record: P34-M01
Type: AI Models

Model type: Linear regression, decision tree and logistic regression at multiple time scales.

Inputs: Geology/trajectory plus whole-run or current-period summaries; 42 paired failure/non failure periods; all-period set 29 fail/891 nonfail.

Outputs: Total life, active hours-to-failure and period failure probability.

Reported performance: Geology+geometry R².41(adj.38); hours-on regression R².75(adj.73), tree.82. Paired classifier TP30, FN12, FP18, TN24=>recall 71.43%, precision 62.5%. All-period fitted TP25, FN4, FP1, TN890=>recall 86.21%, precision 96.15%, but evaluated on fitting data; authors acknowledge optimism and unsuccessful small-data validation.

Advantages: Distinguishes calendar time, active exposure and failure versus other stops.

Limitations: Completed-run summaries leak future information if used as prospective predictors; only 29/42 failure cases; correlated features; no reliable external validation or forecast lead.

Data feasibility: Surface concepts transferable, but SAGD steam/injector/geological inputs absent from stated sources. Ordinary water injection cannot substitute for SAGD steam variables.

Complexity: Medium

Prediction target: Exploratory lifetime association and final-period failure classification.

Lead time qualification: Not quantified; source explicitly describes some predictions as failure happening.

Signals: Current-defined periods, independent event labels and operating context.

Source thresholds: Tree cutoffs are fitted retrospective partitions, not control settings.

Implementation proposal: Use past-only rolling exposure; retain censored runs and competing shutdown reasons; assess survival models with independent future runs.

Recommended future model: Censored survival/competing-risk model with past-only operating exposure.

Review status: Pending

Source caveats: Appendix tree/tables visually verified. Source prose alternates mean/min producer-choke summary names; tree uses MIN_MEDIAN. Higher R² does not establish prospective RUL accuracy.
