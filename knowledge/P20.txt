Knowledge record: P20-M01
Type: AI Models

Model type: ADTree, SVM, naive Bayes; Grubbs outlier test, LOWESS, robust polynomial trends; random-peek semi-supervision.

Inputs: Daily LOWIS measurements; 42 training wells(19 failure), 32 reported test wells(6 failure); intermittent tests carried forward.

Outputs: Normal versus pre-failure.

Reported performance: Held-out SVM TP5, FN1, FP10, TN17 => precision 33.3%, recall 83.3%; ADTree TP1, FN5, FP5, TN22 =>precision 16.7%, recall 16.7%. Both matrices total 33 although text says 32. Table 2 SVM failure error.017, normal.002, overall.026 cannot all be consistent weighted error.

Advantages: Robust trends; distinguishes failure and normal error; adaptation to test-well distribution.

Limitations: Very small event count; random-peek uses unlabeled test distribution (transductive evaluation); high false alarms; inconsistent counts/metrics; smoothing may erase real events.

Data feasibility: No direct ESP reproduction from Avalon/Excel; card/load/rod variables absent. Can reuse causal feature engineering and event-based evaluation design.

Complexity: Medium

Prediction target: Rod pump/tubing failure patterns.

Lead time qualification: One-month examples; evaluation counts alarms within 60 days.14 day/7 day windows are features, not lead.

Signals: Dynamometer/load/runtime and outcome records.

Source thresholds: ADTree negative score; no transferable physical cutoff.

Implementation proposal: For ESP build fresh features; avoid interpreting random-peek test adaptation as untouched prospective validation.

Recommended future model: Robust trend classifier benchmark after ESP-specific redesign.

Review status: Pending

Source caveats: Published test size and cross-validation error arithmetic inconsistent; do not advertise high ESP accuracy from rod data.

Source report: reports/P20.md. PDF page references refer to the original paper, not this text file.
