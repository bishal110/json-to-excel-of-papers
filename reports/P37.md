## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** Generic multilayer neural-network anomaly detector; architecture/loss not disclosed.

**Inputs:** 30 onshore ESPs, 200–500 k W; equipment variants grouped; one-year normal training baseline; surface/downhole telemetry.

**Outputs:** Anomaly level and prioritized advisory.

**Accuracy:** 12 day retrospective example; no precision, recall, confusion matrix, false alerts per well-month or independent event denominator.

**Advantages:** Learns complex normal relationships; can highlight previously unrecognized anomalies.

**Limitations:** Manual training-data curation; repeated tuning on same history; missing cause specificity; limited reproducibility; related publications reuse pilot evidence.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** Potential Avalon-fed monitoring, but full published model uses downhole inputs. A sensor-lost cohort requires new baseline and validation; Excel tests supply contextual evidence rather than fast stream.

**Complexity:** High
