## SECTION 2: OPERATIONAL PROBLEM


**What practical field problem is being solved?:** Failures become obvious after production stops; rig/workover planning takes 30–50 days and occasionally up to three months.

**What production losses are associated with this problem?:** Estimated 28.35% reduction in unscheduled deferment and 1% MTTF improvement; business-case estimates, not demonstrated prospective gains (pp.20–21).

**How would an offshore production engineer recognize this problem?:** Review sustained changes in the required measurements against operating state, recent interventions and valid well tests.

## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** Two random forests with engineered physics/statistical features

**Inputs:** 35 raw channels reduced to 18; static completion/install/failure records; means, differences, SD and calibrated virtual rates/efficiencies. Three years used because physics-derived history limited.

**Outputs:** Binary well failure next 30 days; pump failure next 45 days.

**Accuracy:** Initial well test: TP55, FN42, TN96, FP1; precision 98.2%, recall 56.7%, accuracy 77.8%. Pump test: TP6, FN4, TN21, FP1; precision 85.7%, recall 60%, accuracy 84.4%. Blind 35-well review: well TP17, FN12, TN27, FP2 => precision 89.47%, recall 58.62%, accuracy 75.86%. Pump TP12, FN6, TN28, FP1 => precision 92.31%, recall 66.67%, calculated accuracy 85.11%; paper prints 88.11% and 39 correct although matrix has 40 correct (p.20).

**Advantages:** Physics features and separate component target; blind wells; high positive predictive value in study.

**Limitations:** Small component sample, SME-corrected event dates, balanced initial test prevalence and retrospective review. Roughly 40% well failures missed. Complete 18-feature names not disclosed.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** Not directly from three stated sources alone: requires completion/equipment/failure records and validated physical models; missing downhole sensors remove important inputs. Reduced-signal model requires separate training.

**Complexity:** High
