## SECTION 2: OPERATIONAL PROBLEM


**What practical field problem is being solved?:** Failures and avoidable inefficient operation are buried in large noisy signal collections; accuracy alone misleads for rare events.

**What production losses are associated with this problem?:** No quantified realized production uplift. Abstract reports long-term tubing life error 31 d over 100–600 d lifespans, without detailed supporting model in main results.

**How would an offshore production engineer recognize this problem?:** Rod load/fillage/pressure and dynacard patterns plus event aggregation; ESP applicability is proposed rather than field-tested.

## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** Random forests for failure events; CNN dynacard descriptors; shallow trees/RF for suboptimal states; generalized supervised workflow

**Inputs:** Rod controller, pressure, load, fillage, dynacard and event labels

**Outputs:** Fault/suboptimal-event classes and scores

**Accuracy:** Tubing test accuracy .995, precision .546, hourly recall .421; event detection 80/133=60.2%, 66 false interventions. Pump CV precision .714, accuracy .875, recall .996; event detection 113/172=65.7%, 45 false interventions. CNN descriptor precision/recall vary .596–.955/.651–.983. These are rod results; abstract >99% does not describe all models.

**Advantages:** Whole-well CV, event aggregation, explicit false interventions and quality gates.

**Limitations:** Rod-specific features; imbalance (~1% failure time) inflates accuracy; retrospective labels use later evidence; cannot use those future observations live; small suboptimal-event cohorts.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** No direct ESP reproduction from Avalon/test/pressure sources; methodology transfers after new ESP features/labels. Gas-lift extension is not water-injection evidence.

**Complexity:** High
