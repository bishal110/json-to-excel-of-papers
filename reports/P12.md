## SECTION 2: OPERATIONAL PROBLEM


**What practical field problem is being solved?:** Fragmented data, ambiguous labels and extreme class imbalance impede prospective prediction and cause identification.

**What production losses are associated with this problem?:** COBRA-02 source claims $704,500/event savings in a model-guided counterfactual, but 3400 BOPD×10 d×$80 equals $2,720,000, not printed $272,000. Dates, 312-day run life and downtime also disagree. Not reliable measured savings. KAR-SE04 and Cobra-08 benefits likewise require stronger prospective evidence (PDF pp. 172–176).

**How would an offshore production engineer recognize this problem?:** Electrical loading, pressure, rate and test context linked to installation runs; short-circuit/low-flow/plugging signals plus modeled 30-day risk. Mechanism confirmation requires DIFA.

### P12-D01: Mode then cause

**Rule ID:** P12-D01

**IF:** Observed component/function failure established

**AND:** Operating, installation and DIFA evidence assembled

**THEN:** Record mode separately from one or more supported causes

**Engineering Explanation:** Motor short is an observed mode, not a sufficient root cause

**Confidence:** High

**Evidence / status:** PDF pp. 77–88; author logic or explicitly identified derived rule. This record is not an approved control rule.

**Rule ID:** P12-D02
