## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** BP neural network 45 inputs–15 hidden–10 outputs plus analytical pressure-buildup model.

**Inputs:** Field and synthetic current cards; abstract training across>900 wells; at least 50 simulated examples per class; 45 features from 24 h cards; hydraulic model needs fluid/completion/pump curve.

**Outputs:** Ten current-card classes plus hydraulic diagnosis.

**Accuracy:** No held-out aggregate accuracy. Case output 57% normal, 12.3% sand failed to identify leak; pressure method led to confirmed tubing leak.

**Advantages:** Directly addresses absence of downhole sensors using additional surface test evidence.

**Limitations:** Synthetic training and validation not fully characterized; current classes overlap; Figure 5 rendering partly corrupted; empirical 0.78/1.5/1 cutoffs not universal.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** Current features possible from Avalon; full pressure method needs dedicated time-resolved test and extra completion/PVT/curve data. Routine Excel pressures/tests alone insufficient.

**Complexity:** High
