## SECTION 2: OPERATIONAL PROBLEM


**What practical field problem is being solved?:** Manual dynamometer interpretation misses early patterns and recorded failure dates lag physical events.

**What production losses are associated with this problem?:** Workover downtime, deferred production and labor; no measured economic reduction.

**How would an offshore production engineer recognize this problem?:** Changes in rod-pump load/card/runtime/production features; these are not ESP signals.

## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** Ada BNet (Ada Boost+Bayesian networks) and Ada DT (Ada Boost+decision trees)

**Inputs:** 14+ daily rod-pump attributes with expert preprocessing and normalization

**Outputs:** Normal, tubing failure, rod failure and pre-signal classes

**Accuracy:** Narrative reports Ada BNet normal 97.7%, failure 91.9%; Table 3 has transposed/inconsistent labels/count orientation. Ada DT ~95% best at 80–180 iterations. Training-table 'percent' entries are actually fractional-looking errors; do not reproduce as <0.12% without correction.

**Advantages:** Single field model rather than one per well; well-level evaluation.

**Limitations:** Rod systems; recorded-date bias; missing-data fill; table inconsistencies; claimed proof of no overfitting contradicted by reported overfit above 180 iterations; record-level CV may leak within wells.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** No direct ESP implementation with Avalon/tests/pressures: rod card/load inputs missing. General workflow transferable.

**Complexity:** Medium
