## SECTION 3: FAILURE MODES IDENTIFIED


### P10-F01: Gas interference / gas lock

**Failure Mode:** Gas interference / gas lock

**Category:** Pump

**Symptoms:** Current fluctuation or motor cycling

**Root Causes:** High gas fraction / loss of cooling liquid

**Consequences:** Inefficiency, overheating and mechanical damage risk

**Typical Field Indicators:** Current variability, runtime

**Confidence Level:** Medium

**Evidence:** p. 2

### P10-F02: Scaling / flow restriction

**Failure Mode:** Scaling / flow restriction

**Category:** Pump

**Symptoms:** Cycling with insufficient cooling

**Root Causes:** Reduced liquid throughput

**Consequences:** Thermal trips and degradation

**Typical Field Indicators:** Repeated current/voltage on-off cycles

**Confidence Level:** Low

**Evidence:** p. 2

### P10-F03: Solids-related loading

**Failure Mode:** Solids-related loading

**Category:** Pump

**Symptoms:** Current spikes, possible restart

**Root Causes:** Solids intermittently increase pumping load

**Consequences:** Overheating / breakdown risk

**Typical Field Indicators:** Spike statistics and cycling

**Confidence Level:** Medium

**Evidence:** p. 2

### P10-F04: Motor overheating

**Failure Mode:** Motor overheating

**Category:** Motor

**Symptoms:** Repeated protective shutdown/restart

**Root Causes:** Insufficient cooling flow

**Consequences:** Lost runtime and eventual damage

**Typical Field Indicators:** Cycling inferred from electrical series

**Confidence Level:** Medium

**Evidence:** p. 2

### P10-F05: Missing / irregular sensor records

**Failure Mode:** Missing / irregular sensor records

**Category:** Sensor

**Symptoms:** Negative voltage, impossible amps or prolonged gaps

**Root Causes:** Data error/telemetry; cause not necessarily failure

**Consequences:** Misleading diagnosis

**Typical Field Indicators:** Bounds and missingness percentage

**Confidence Level:** Medium

**Evidence:** p. 3

## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** Linear-kernel SVM with domain-engineered daily features and sliding-window ratios; hyperparameters cross-validated

**Inputs:** Current, voltage, frequency, runtime and quality/event labels

**Outputs:** Normal versus anomaly/inefficiency

**Accuracy:** Overall precision 61.8%, recall 61.5%; FMT1 62.5%/70%; FMT2 50%/33.3%. Separate years used for train/test; hundreds of wells. TP-I event recall and TP-II alert precision use ±90-day matching and differ in counting.

**Advantages:** No downhole sensor needed; fleet normalization and practical electrical features.

**Limitations:** Labels subjective; inefficiency versus failure confused; 90-day window can inflate usefulness; no fixed RUL; copying prior data can manufacture patterns.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** Avalon alone conditionally sufficient for scoring if four raw tags and history exist; event/maintenance labels still needed for training. Tests/surface pressures useful for diagnosis, not original inputs.

**Complexity:** Medium
