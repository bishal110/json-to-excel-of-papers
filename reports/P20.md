## SECTION 3: FAILURE MODES IDENTIFIED


### P20-F01: Rod pump failure

**Failure Mode:** Rod pump failure

**Category:** Pump

**Symptoms:** Abnormal dynamometer/load/runtime trends; sometimes abrupt.

**Root Causes:** Wear/design/manufacturing, solids/gas and corrosive fluids; no unique model cause.

**Consequences:** Production loss and workover.

**Typical Field Indicators:** Rod-pump-specific load-card features.

**Confidence Level:** Medium for rod pumps; Low transfer to ESP

**Evidence:** Methods and field cases

### P20-F02: Tubing leak

**Failure Mode:** Tubing leak

**Category:** Pump

**Symptoms:** Loss of useful production while pump may keep operating.

**Root Causes:** Mechanical wear/rod cutting and corrosion.

**Consequences:** Recirculation and sustained production loss.

**Typical Field Indicators:** Dynamometer card shrinkage plus production evidence.

**Confidence Level:** Medium for rod pumps

**Evidence:** Problem description

## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** ADTree, SVM, naive Bayes; Grubbs outlier test, LOWESS, robust polynomial trends; random-peek semi-supervision.

**Inputs:** Daily LOWIS measurements; 42 training wells(19 failure), 32 reported test wells(6 failure); intermittent tests carried forward.

**Outputs:** Normal versus pre-failure.

**Accuracy:** Held-out SVM TP5, FN1, FP10, TN17 => precision 33.3%, recall 83.3%; ADTree TP1, FN5, FP5, TN22 =>precision 16.7%, recall 16.7%. Both matrices total 33 although text says 32. Table 2 SVM failure error.017, normal.002, overall.026 cannot all be consistent weighted error.

**Advantages:** Robust trends; distinguishes failure and normal error; adaptation to test-well distribution.

**Limitations:** Very small event count; random-peek uses unlabeled test distribution (transductive evaluation); high false alarms; inconsistent counts/metrics; smoothing may erase real events.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** No direct ESP reproduction from Avalon/Excel; card/load/rod variables absent. Can reuse causal feature engineering and event-based evaluation design.

**Complexity:** Medium
