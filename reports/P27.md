## SECTION 8: MACHINE LEARNING / AI CONTENT


**Model Type:** PCA to 3 dimensions plus least-squares enclosing sphere.

**Inputs:** 13 variables, 20 min samples, 174538 stable records from 47 wells; 40 normal comparison wells use daily report data.

**Outputs:** Stable versus anomalous/failure trajectory.

**Accuracy:** TP20, FN27, TN40, FP0; event recall 42.55%, calculated overall accuracy 68.97%, observed precision 100% in this small selected sample. Paper calls 42.5%'accuracy' but it is failure recall.3 PCs retain~70% variance.

**Advantages:** Simple interpretable healthy-boundary monitor; explicitly reports missed failures.

**Limitations:** Normal/failure sampling resolution differs; only 70% variance retained; 20 min samples miss fast dynamics; same wells contribute healthy/failure periods; small selected normal set.

**Can it be implemented using only Avalon Data / Production Test Data / Surface Pressure Data?:** Needs 13 inputs including downhole signals and choke. Sensor-lost model requires new baseline and separate validation; daily Excel context does not recreate 20 min telemetry.

**Complexity:** Medium
